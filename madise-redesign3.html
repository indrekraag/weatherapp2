Annotated Audit

Issues spotted in the current build

Inconsistencies ●

  • Material drift. 11 named "Presets" all left in CSS as comments, but the active card uses --surface at .82 alpha while inner tiles (.hour, .day-card) use rgba(20,30,45,.55). Three different glass recipes coexist.
  • Border colour conflict. Outer cards: white hairline (.08). Inner tiles: cyan border (.18). Buttons: cyan (.3). The eye reads three different materials.
  • Bevel inconsistency. Hour/day tiles still carry the old chamfered bevel (inset 0 1px 0 rgba(255,255,255,0.15)) but the parent card has dropped it (Preset 11 "flat diffused glass"). Children look 3D, parent looks flat.
  • Type stack split. SF Mono for ~14 named selectors, system sans for the rest. Numbers in .hour-rain and pollen .val fall back to sans — they break tabular alignment.
  • Label vocabulary. Tundub / Kastepunkt are sentence-case; TUUL / SADU / ÕHURÕHK are uppercase + letter-spaced. Both label the same kind of thing.
  • Location naming. App title is "Madise" but nearby station "Kurevere" is in the hero card. No location label visible in the topbar — only the clock. Add a header so it's clear which house you're checking.

Readability ●

  • Wall-of-rows hero card. 8 stacked label/value rows + 3 stations = 11 lines of essentially the same visual rhythm. Hard to scan; the eye has no anchor.
  • Big temp competes with itself. 50px temp + 14px Tundub/Kastepunkt in the same column, plus condition icon + 2 buttons on the right side: 5 elements in a 200px-wide row.
  • Muted text too muted. --muted = rgba(200,225,245,0.96)·0.7 (via opacity) on dim glass = ~3:1 against the background — below WCAG AA for body text. Bumped to .74 alpha (no opacity multiplier) in the redesign.
  • Wind arrow is a Unicode glyph. "↑" rotates via CSS transform, but the glyph itself has a non-uniform stroke so off-axis rotations look bent. SVG triangle reads cleaner at every angle.
  • "Hoiatusi pole" is a dashed empty box. Reads as "this section failed to load." Make it a calm green "OK" affordance instead.

Liquid-glass execution ●

  • No refraction. Surface alpha .82 + body bg solid means there's nothing for the glass to refract. Drop surface to ~.62, push backdrop blur to 28px, let the coloured body blobs bleed through.
  • Eleven bevel layers. The committed Preset 10 stacks 11 box-shadows on every card. Apple's actual Liquid Glass uses ~3 layers max (rim light, drop, contact). Heavier ≠ glassier.
  • Atmosphere is static. Comment claims "animation removed for verifiability" — but a gentle ~20s drift on the body blob field is what sells the material. Honour prefers-reduced-motion.
  • Highlight is uniform. Top inset highlight runs full-width. A real bevel catches light in a band — try a 1px gradient bar inset from the edges by ~12%.

Information hierarchy ●

  • 7-day forecast loses temperature shape. Equal-size mini cards make every day look identical. A horizontal min→max range bar lets you spot the cold day and the warm day instantly.
  • Pollen / aurora are mute numbers. "Üldine: Mõõd" tells you nothing visually. Gauge bars (lo / mid / hi colour) make state readable at a glance.
  • Three nearby stations stacked vertically eat 90+px. They're peer data — three horizontal chips do the job in 60px and read as a comparison set.
  • Topbar wastes a row. "Uuendatud — ↻ ⟲" with two near-identical refresh buttons. A status dot + relative time + single tap-target is more honest about state.
  • Radar/Sat buttons hide bottom-right. Absolute-positioned 10px text inside the hero. Promote to a full-width segmented toggle below the temp — they're the primary action of the whole app.

Small fixes that punch above their weight ●

  • Delete all 11 preset comment blocks — they're 130 lines of dead code at the top of the file. Move to DESIGN.md in the repo.
  • Use font-feature-settings: "tnum" 1 globally for numbers instead of per-class opt-in.
  • Make the title font weight 200 for the big temperature (Apple Weather does this). 700 + 50px feels heavy; 200 + 72px feels temperature.
  • Use a vector wind arrow (rotated SVG triangle), not "↑".
  • Sun and moon cards: cap the rise/set/length section to 3 rows; drop the icon-only column — labels do the work.
  • Add a "Min tonight" prediction to Öökülm — the binary "yes/no" wastes the slot when you could show min +6° kl 04:30.
